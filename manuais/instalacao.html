Instalação e solução de problemas

Executar no Windows

Recomendado: VS Code com extensão Live Server ou XAMPP/Apache. O jogo importa Three.js por CDN e precisa de conexão com a internet na configuração atual.

Com Python instalado

cd D:\Ferramentas\WMK-Combined-Arms
py -m http.server 4173

Abra http://127.0.0.1:4173/ no navegador. Alternativamente, copie o repositório para htdocs do XAMPP e acesse via localhost.

Clonar

git clone https://github.com/WalneyNF/WMK-Combined-Arms.git
cd WMK-Combined-Arms
