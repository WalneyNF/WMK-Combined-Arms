O que é WMK Combined Arms?

Protótipo de combate 3D desenvolvido em HTML, CSS, JavaScript e Three.js. O jogo cria uma ilha procedural, com base militar, pista de pouso, porto, vegetação, água e unidades hostis.

Começando

  1. Abra o projeto por servidor HTTP (consulte Instalação).
  2. Na tela inicial, selecione Iniciar missão.
  3. Escolha helicóptero (1), tanque (2) ou navio (3).
  4. Use WASD para controlar movimento e Espaço para arma primária.
  5. Observe radar, integridade, velocidade, altitude e objetivo.
  6. Neutralize 8 inimigos para completar a missão demonstrativa.

Elementos da interface

Radar 360°: localização relativa dos inimigos
Painel de missão: eliminações e progresso
Painel de alvo: nome, distância e integridade
Retículo: referência central da mira
Painel de armas: arma e recarga
Seletor de veículos: teclas 1, 2 e 3
O projeto é um protótipo. Editor visual, campanha persistente e multiplayer constam no roadmap e não são recursos prontos na versão inicial.
