Arquitetura técnica

Estado atual

A implementação inicial é um único index.html com HTML, CSS e JavaScript módulo importando three@0.161.0 por CDN. Isso facilita executar, mas dificulta manutenção.

Arquitetura-alvo (a implementar)

src/
  core/       Game, Clock, EventBus, Settings, ResourceManager
  world/      Terrain, Ocean, Props, SpawnSystem
  vehicles/   Vehicle, Helicopter, Tank, Ship
  combat/     Weapon, Projectile, DamageSystem
  ai/         Bot, StateMachine, Waypoint
  missions/   MissionManager, Trigger, Objective
  editors/    SceneEditor, Gizmo, UndoRedo
  ui/         HUD, Hangar, Settings

Contrato dos dados

Conteúdo editável usa JSON com schemaVersion e id imutável, evitando scripts arbitrários em arquivos importados. Exemplos ficam em data/exemplos.

{
  "schemaVersion": 1,
  "id": "wmk-tank-001",
  "name": "Tanque de treinamento",
  "kind": "tank",
  "maxHealth": 100,
  "maxSpeed": 18,
  "turnRate": 0.8,
  "weaponId": "wmk-cannon-001"
}

Desempenho

Separar atualização de física em passo fixo, limitar delta, usar instanciamento para vegetação, pooling para munições e shaders para ondas. A cada alteração medir draw calls, FPS e memória em equipamentos modestos.

Segurança

Validar JSON antes de importar, limitar tamanho de arquivos e quantidade de objetos; nunca executar scripts extraídos de conteúdo de terceiros. Para futuro multiplayer, manter servidor autoritativo para dano e pontuação.
