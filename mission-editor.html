Arraste objetivos pela ordem usando os botões ↑ e ↓. Cada objetivo é avaliado independentemente.

02 · MAPA TÁTICO · CLIQUE PARA DEFINIR DESTINO

Clique no mapa para posicionar o objetivo selecionado. Os pontos vermelhos são inimigos; verdes, aliados. O raio do objetivo aparece em amarelo. Coordenadas usam o mesmo mundo do laboratório.

O editor salva definições JSON. Testar missão envia a definição ao laboratório no mesmo navegador, sem reescrever o mapa e sem criar novos veículos. IDs de unidades devem existir no laboratório.
